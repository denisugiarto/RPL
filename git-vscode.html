01 // Persiapan

Yang Kamu Perlukan

3 hal wajib sebelum mulai. Kalau belum ada, jangan khawatir — langkah berikutnya akan menjelaskan cara menginstallnya.

VS Code

Editor kode gratis dari Microsoft. Tempatmu menulis kode sekaligus mengelola Git.

💡 Unduh di code.visualstudio.com

Git

Mesin di balik semua fitur version control. Wajib diinstall di laptop.

💡 Unduh di git-scm.com

Akun GitHub

Tempat kode kamu disimpan di cloud dan bisa dibagikan ke teman.

💡 Daftar gratis di github.com

🎯 TARGET TUTORIAL INI:
Di akhir tutorial, kamu bisa membuat repository di GitHub dari VS Code dan mengirim (push) kode pertamamu ke sana. Semua tanpa menulis perintah Git di terminal — cukup klik-klik!
02 // Persiapan

Install Git

Buka git-scm.com, klik tombol Download, lalu install seperti biasa (cukup klik Next terus sampai selesai).

terminal — cek versi git
# Setelah install, cek apakah Git sudah terpasang
$ git --version
git version 2.43.0
# Kalau muncul versi seperti di atas, berarti Git siap! ✅
1
Buka Git Bash / Terminal

Di Windows: klik kanan desktop → "Git Bash Here". Di Mac: buka app Terminal.

2
Setel nama & email kamu

Git mencatat siapa pembuat commit. Isi dengan nama dan email akun GitHub-mu.

3
Selesai! Cek versi

Jalankan git --version untuk memastikan semua berjalan.

terminal — set identitas
$ git config --global user.name "NamaKamu"
$ git config --global user.email "emailkamu@gmail.com"
# Ganti NamaKamu dan email dengan data akun GitHub-mu!

05 // Login

Login GitHub di VS Code

Inilah langkah pentingnya: hubungkan VS Code dengan akun GitHub kamu agar bisa push kode.

1
Klik ikon akun di pojok kiri bawah

Ikon lingkaran/avatar di kiri bawah VS Code (di bawah ikon ⚙️ pengaturan).

2
Klik "Sign in to GitHub"

Dari menu itu pilih Sign in to GitHub. Browser akan terbuka otomatis.

3
Authorize di browser

Login ke GitHub di browser (kalau belum) lalu klik Authorize Visual Studio Code.

4
Kembali ke VS Code — selesai! ✅

VS Code akan otomatis selesai login. Nama/avatar GitHub-mu muncul di pojok kiri bawah.

VS Code — notifikasi login
# Cara lain: dari panel Source Control
● Sign in to GitHub
# VS Code akan meminta izin:
→ Open GitHub website
→ Login & click Authorize
✓ You have successfully signed in to GitHub!
# Alternatif (bukan via browser):
Sign in with a Personal Access Token
di github.com → Settings → Developer settings → Personal access tokens
⚠️ PERHATIAN:
Kalau muncul pilihan Personal Access Token, pilih opsi browser yang lebih mudah. Token hanya untuk yang sudah mahir — untuk pemula, login lewat browser jauh lebih simpel dan aman.

Stage perubahan (klik tanda +)

Di panel Source Control, klik ikon + pada file untuk menandainya siap disimpan.

Misalnya: "membuat halaman pertama". Pesan yang jelas membantu kita ingat apa yang berubah.

Perubahan tersimpan di repository lokal. Kalau ada dialog "Always sign commits" → klik Yes saja.

🎯 INGAT

Commit = save game. Masih di laptop sendiri dan belum sampai ke GitHub. Untuk mengirim ke GitHub, kita lanjut ke langkah push berikutnya!

07 // Push ke GitHub

Push ke GitHub

Commit pertama sudah jadi. Sekarang saatnya mengirim kode ke GitHub agar tersimpan di cloud dan bisa dibagikan.

1
Klik "Publish Branch"

Setelah commit pertama, muncul tombol biru Publish Branch di panel Source Control.

2
Pilih nama repository

VS Code menyarankan nama sesuai nama folder. Boleh diganti lalu tekan Enter.

3
Pilih Private atau Public

Public = siapa saja bisa lihat. Private = hanya kamu. Untuk tugas, Public boleh.

4
Selesai! 🎉

Repository tercipta di GitHub dan kode berhasil ter-push. Cek di github.com → profilmu → tab Repositories.

Git — yang terjadi di belakang layar
# Ketika kamu klik Publish Branch,
# VS Code menjalankan ini:
$ git remote add origin https://github.com/kamu/proyek-pertamaku.git
$ git push -u origin main
✓ Branch 'main' set up to track 'origin/main'.
✓ Everything up-to-date
# Untuk commit berikutnya, cukup:
+ stage file → tulis pesan → Commit
→ lalu klik Sync Changes (ikon 🔄 bawah) = push + pull sekaligus
08 // Alur Kerja

Commit & Push Berikutnya

Setelah repository pertama tercipta, alur kerja selanjutnya selalu sama. Cukup 3 langkah:

1

Edit Kode

Ubah atau tambah file seperti biasa. VS Code akan otomatis mendeteksi perubahannya.

2

Stage + Commit

Klik +, tulis pesan, klik Commit.

3

Push / Sync

Klik ikon Sync Changes (🔄) untuk mengirim ke GitHub.

alur-kerja — 3 langkah sakti
# Kalau kamu mau pakai terminal, perintahnya:
$ git add . # tandai semua perubahan
$ git commit -m "perbaiki tampilan" # simpan
$ git push # kirim ke GitHub
✓ 1 file changed, 3 insertions
✓ To github.com:kamu/proyek-pertamaku.git
🔁 SIKLUS

Edit → Stage → Commit → Push, lalu ulangi lagi! Ini adalah ritual harian seorang programmer. Semakin sering commit, semakin rapi riwayat kerjamu.

10 // Solusi

Masalah yang Sering Terjadi

Tenang, kalau ada yang error — ini solusi untuk masalah paling umum.

❌

"Please tell me who you are"

Kamu belum mengisi nama & email di Git.

git config --global user.name "Nama"
git config --global user.email "email"
🔒

"Authentication failed"

Login GitHub belum selesai atau token salah. Ulangi proses login di VS Code: ikon akun → Sign in to GitHub.

🌳

"Repository not found"

Repository di GitHub tidak ditemukan. Pastikan sudah pernah di-publish, atau nama remote benar.

↩️

"Rejected / non-fast-forward"

Ada perubahan dari teman yang belum kamu ambil. Klik Sync Changes atau git pull dulu, baru push lagi.

💡 GOLDEN RULE: Kalau bingung dengan pesan error di terminal, salin teks errornya lalu cari di Google / chat AI. Jangan menyerah — semua programmer pernah ngalamin error yang sama!
