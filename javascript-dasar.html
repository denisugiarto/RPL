Materi web front-end · Kelas X RPL

JavaScript membuat web merespons.

Pelajari cara memberi instruksi pada halaman web: mengolah data, mengambil keputusan, dan menanggapi tindakan pengguna.

app.js
const tombol = document
  .querySelector("#tombol");

tombol.addEventListener(
  "click",
  function () {
    console.log("Tombol ditekan!");
  }
);

Mulai dari dasar

Dari baris kode ke fitur web

Prasyaratnya: sudah mengenal elemen HTML dan aturan CSS sederhana.

GO Setelah belajar, kamu bisa
  • Menulis dan menjalankan JavaScript di browser.
  • Mengolah nilai dengan variabel, operator, kondisi, perulangan, fungsi, dan array.
  • Mengubah halaman saat pengguna berinteraksi.
  • Memvalidasi formulir dan menampilkan hasil yang mudah dipahami.
IDE Siapkan alat
  • Visual Studio Code untuk menulis kode.
  • Browser modern seperti Chrome, Edge, atau Firefox.
  • DevTools browser untuk membuka tab Console.
  • Folder latihan berisi file HTML dan JavaScript.
JavaScript akan dijalankan di browser. Belum perlu memasang framework atau server.

Fondasi halaman web

HTML menyiapkan elemen, JavaScript memberi perilaku

Simpan kode JavaScript di file terpisah agar mudah dibaca dan dirawat.

01 Struktur folder
latihan-js/
├── index.html
└── app.js

Kedua file harus berada di folder yang sama agar alamat app.js ditemukan.

index.html
<!doctype html>
<html lang="id">
  <head>
    <meta charset="utf-8">
    <script src="app.js" defer></script>
  </head>
  <body>
    <h1>Latihan JavaScript</h1>
  </body>
</html>
defer membuat browser menjalankan file setelah HTML selesai dibaca.
Coba: buat kedua file, hubungkan app.js, lalu tulis console.log("Siap belajar!");.

Tempat bereksperimen

Mulai dengan Console

Console adalah tempat browser menampilkan pesan, hasil perhitungan, dan kesalahan JavaScript.

app.js
console.log("Halo, RPL!");
console.log(2 + 3);
console.warn("Ini contoh peringatan");
F12 Cara membuka Console
  1. Buka halaman latihan di browser.
  2. Tekan F12 atau klik kanan lalu pilih Inspect.
  3. Pilih tab Console.
  4. Periksa pesan dan baris kode saat terjadi kesalahan.
Tanda titik koma membantu memisahkan instruksi. Biasakan menulis kode dengan rapi.
Coba: tampilkan nama, kelas, dan hasil dari 12 * 4 di Console.

Menyimpan informasi

Variabel memberi nama pada nilai

Gunakan const untuk nilai yang tidak diganti. Gunakan let jika nilainya perlu berubah.

app.js
const nama = "Naya";
let nilai = 80;
const sudahMengumpulkan = true;

nilai = 88;
console.log(nama, nilai);
console.log(typeof sudahMengumpulkan);
STR Teks

"Naya" atau 'RPL'. Teks ditulis di antara tanda kutip.

NUM Angka

88 atau 3.5. Angka bisa dipakai dalam perhitungan.

T/F Boolean

true atau false. Nilai ini sering dipakai untuk kondisi.

const tidak membuat isi objek atau array menjadi kebal perubahan; yang tidak bisa diganti adalah ikatan variabelnya.
Coba: buat variabel nama produk, harga, dan status tersedia. Tampilkan semuanya di Console.

Mengolah nilai

Operator mengubah data menjadi hasil

app.js
const harga = 12000;
const jumlah = 3;
const total = harga * jumlah;

const nama = "Roti";
const pesan = "Produk: " + nama;
console.log(pesan, total);
+ Operator yang sering dipakai
  • Aritmetika: + - * / %
  • Perbandingan: === !== > < >= <=
  • Logika: && (dan), || (atau), ! (kebalikan)
Gunakan === untuk membandingkan nilai dan tipe data sekaligus.

Gabungkan teks

Tanda + bisa menjumlahkan angka atau menyambung teks. Perhatikan tipe datanya.

const umur = 16;
const umurAngka = Number("16");

Template literal

Gunakan tanda backtick untuk menyisipkan nilai ke dalam teks.

const nama = "Naya";
console.log(`Halo, ${nama}!`);
Coba: hitung total harga dari harga barang dan jumlah pembelian, lalu tampilkan dalam kalimat.

Membuat keputusan

if memilih tindakan berdasarkan syarat

Kondisi menghasilkan nilai boolean: benar (true) atau salah (false).

app.js
const nilai = 82;

if (nilai >= 75) {
  console.log("Tuntas");
} else {
  console.log("Perlu latihan lagi");
}
IF Cara membacanya
  • Periksa apakah nilai minimal 75.
  • Jika syarat benar, jalankan isi blok if.
  • Jika syarat salah, jalankan isi blok else.
Gunakan else if jika ada lebih dari dua kemungkinan. Urutkan syarat dari batas tertinggi.
Beberapa kategoricontoh
let predikat;
if (nilai >= 85) { predikat = "A"; }
else if (nilai >= 75) { predikat = "B"; }
else { predikat = "C"; }
Coba: buat aturan diskon. Jika belanja minimal Rp100.000, tampilkan pesan bahwa pembeli mendapat diskon.

Mengulang instruksi

Perulangan menghemat penulisan kode berulang

Pakai for jika batas pengulangan sudah diketahui.

app.js
for (
  let nomor = 1;
  nomor <= 5;
  nomor++
) {
  console.log("Baris ke-" + nomor);
}
FOR Tiga bagian for
  • let nomor = 1: nilai awal.
  • nomor <= 5: syarat untuk lanjut.
  • nomor++: menaikkan nomor setelah satu putaran.
Pastikan nilai berubah menuju batas akhir. Jika syarat selalu benar, perulangan tidak berhenti.

Perulangan while

Cocok saat pengulangan berjalan selama sebuah kondisi masih benar.

let hitung = 3;
while (hitung > 0) {
  console.log(hitung);
  hitung--;
}
Coba: tampilkan angka 1 sampai 10 dan hitung jumlah seluruh angka itu.

Merapikan logika

Fungsi menyimpan langkah yang bisa dipakai ulang

Masukkan data lewat parameter, lalu kembalikan hasil dengan return.

app.js
function hitungRataRata(a, b, c) {
  return (a + b + c) / 3;
}

const rata = hitungRataRata(
  80, 90, 70
);
console.log(rata); // 80
ƒ Bagian fungsi
  • function memulai deklarasi fungsi.
  • hitungRataRata adalah nama fungsi.
  • a, b, c adalah parameter.
  • return mengirim hasil kembali ke pemanggil.

Panggil

Berikan nilai yang akan diproses.

Terima

Parameter menerima nilai masukan.

Olah

Jalankan instruksi dalam fungsi.

Kembalikan

Gunakan hasil dari return.

Coba: buat fungsi yang menerima harga dan jumlah barang, lalu mengembalikan total pembayaran.

Mengelola kumpulan data

Array menyimpan beberapa nilai dalam satu variabel

Posisi array dimulai dari indeks 0. Gunakan length untuk mengetahui jumlah isinya.

app.js
const nilai = [80, 90, 75];
console.log(nilai[0]); // 80

nilai.push(88);
let total = 0;

for (const angka of nilai) {
  total += angka;
}

const rata = total / nilai.length;
[ ] Yang perlu diingat
  • nilai[0] mengambil isi pertama.
  • push() menambahkan nilai di akhir.
  • for...of membaca setiap isi array.
  • length memberi jumlah data.
Nilai array yang dibuat dengan const tetap bisa diubah isinya. Yang tidak bisa diganti adalah variabel nilai agar menunjuk ke array lain.
Coba: simpan tiga nama teman dalam array, lalu tampilkan setiap nama dengan perulangan.

JavaScript bertemu halaman

DOM adalah representasi HTML yang bisa diubah

Pilih elemen dengan selector, lalu ubah teks atau kelasnya.

index.html
<h1 id="judul">Selamat datang</h1>
<p class="status">Belum aktif</p>
app.jspilih dan ubah
const judul =
  document.querySelector("#judul");
const status =
  document.querySelector(".status");

judul.textContent = "Halo, RPL!";
status.classList.add("aktif");
DOM Selector dasar
  • "#judul" memilih elemen dengan id="judul".
  • ".status" memilih elemen dengan kelas status.
  • textContent mengganti teks.
  • classList.add() menambahkan kelas CSS.
Gunakan textContent untuk menampilkan teks dari pengguna. Jangan memasukkan teks pengguna dengan innerHTML.
Coba: pilih elemen judul, lalu ubah teksnya. Tambahkan kelas CSS yang mengubah warna judul.

Menerima masukan

Periksa input sebelum memprosesnya

Validasi membantu pengguna memperbaiki data yang kosong atau tidak sesuai.

index.html
<form id="formNama">
  <label for="nama">Nama</label>
  <input id="nama" required>
  <button type="submit">Kirim</button>
</form>
<p id="pesan" aria-live="polite"></p>
app.jsvalidasi sederhana
const form =
  document.querySelector("#formNama");
const input =
  document.querySelector("#nama");
const pesan =
  document.querySelector("#pesan");

form.addEventListener("submit",
  function (event) {
    event.preventDefault();
    const nama = input.value.trim();
    if (nama === "") {
      pesan.textContent = "Nama wajib diisi.";
      return;
    }
    pesan.textContent = "Halo, " + nama;
  }
);

submit

Berjalan ketika formulir dikirim.

preventDefault()

Mencegah halaman dimuat ulang secara otomatis.

trim()

Menghapus spasi di awal dan akhir teks.

Coba: tambahkan validasi agar nilai hanya boleh diisi dengan angka dari 0 sampai 100.

Proyek akhir · rancang alurnya

Kalkulator nilai siswa

Gabungkan formulir, validasi, perhitungan, fungsi, kondisi, dan DOM dalam satu halaman.

Masukkan

Nama dan tiga nilai mata pelajaran.

Periksa

Nama tidak kosong; nilai berada di rentang 0–100.

Hitung

Jumlahkan nilai, lalu bagi dengan banyaknya nilai.

Tampilkan

Perlihatkan nama, rata-rata, dan predikat.

A–D Aturan contoh predikat
  • Rata-rata 85 atau lebih: A
  • Rata-rata 75 sampai kurang dari 85: B
  • Rata-rata 65 sampai kurang dari 75: C
  • Di bawah 65: D

Ambang ini hanya contoh untuk latihan. Guru dapat menggantinya sesuai kebutuhan kelas.

✓ Kriteria hasil
  • Perhitungan rata-rata benar.
  • Input kosong atau di luar rentang ditangani.
  • Fungsi dan percabangan dipakai dengan jelas.
  • Pesan hasil mudah dibaca.
Mulai: buat form HTML dan elemen hasil sebelum menulis logika JavaScript.

Proyek kalkulator · siapkan HTML

Buat form dan tempat hasil

index.htmlstruktur inti
<form id="formNilai">
  <label for="nama">Nama</label>
  <input id="nama" required>

  <label>Nilai Bahasa Indonesia
    <input class="nilai" type="number"
      min="0" max="100" required>
  </label>
  <label>Nilai Matematika
    <input class="nilai" type="number"
      min="0" max="100" required>
  </label>
  <label>Nilai Produktif
    <input class="nilai" type="number"
      min="0" max="100" required>
  </label>

  <button type="submit">Hitung nilai</button>
</form>
<p id="hasil" aria-live="polite"></p>
</> Kenapa atribut ini dipakai?
  • required meminta pengguna mengisi input.
  • type="number" memudahkan input angka.
  • min dan max memberi batas nilai.
  • aria-live membantu pembaca layar mengumumkan hasil baru.
Atribut HTML memberi pemeriksaan awal. JavaScript tetap perlu memastikan data sebelum dihitung.
Periksa: setiap label jelas, input memiliki batas, dan tombol berada di dalam form.

Proyek kalkulator · tulis JavaScript

Validasi, hitung, lalu tampilkan

Pecah aturan predikat menjadi fungsi agar logika utama mudah dibaca.

app.jsfungsi predikat
function tentukanPredikat(rata) {
  if (rata >= 85) return "A";
  if (rata >= 75) return "B";
  if (rata >= 65) return "C";
  return "D";
}
app.jsevent formulir
const form = document.querySelector("#formNilai");
const namaInput = document.querySelector("#nama");
const inputNilai = document.querySelectorAll(".nilai");
const hasil = document.querySelector("#hasil");

form.addEventListener("submit", function (event) {
  event.preventDefault();
  const nama = namaInput.value.trim();
  const nilai = [];
  for (const input of inputNilai) {
    nilai.push(input.valueAsNumber);
  }

  let valid = nama !== "" && nilai.length > 0;
  for (const angka of nilai) {
    if (!Number.isFinite(angka) || angka < 0 || angka > 100) valid = false;
  }
  if (!valid) {
    hasil.textContent = "Periksa nama dan nilai (0–100).";
    return;
  }

  let total = 0;
  for (const angka of nilai) total += angka;
  const rata = total / nilai.length;
  hasil.textContent = nama + ": rata-rata " +
    rata.toFixed(1) + " · predikat " + tentukanPredikat(rata);
});
textContent menampilkan hasil sebagai teks. toFixed(1) membatasi rata-rata menjadi satu angka di belakang koma.

Demo yang bisa dicoba

Hitung rata-rata dan predikat

Masukkan nama dan nilai 0–100. Aturan predikat sama dengan contoh proyek.

Hasil perhitungan akan muncul di sini.

TRY Cek beberapa contoh
  • Nilai 90, 80, 70 → rata-rata 80 → predikat B.
  • Nilai 100, 90, 80 → rata-rata 90 → predikat A.
  • Nilai 50, 60, 70 → rata-rata 60 → predikat D.
Coba masukkan desimal atau nilai kosong. Browser akan membantu menolak input yang tidak sesuai.
Modifikasi: tambahkan mata pelajaran lain, lalu pastikan rata-rata memakai jumlah input terbaru.
