Data tersusun, tersimpan, lalu terhubung

Gunakan konsep dasar untuk membuat fitur yang mengelola data lebih nyata.

{ } Susun data

Kelompokkan informasi terkait ke dalam objek dan daftar objek.

DB Simpan data

Ubah objek menjadi JSON lalu simpan di browser dengan localStorage.

API Ambil data

Minta data dari API, tunggu hasilnya, dan tampilkan keadaan berhasil atau gagal.

Kita tetap memakai variabel, fungsi, array, DOM, dan event dari materi dasar.

Data yang saling berkaitan

Objek menyimpan satu entitas

Objek mengelompokkan beberapa nilai dengan nama properti yang mudah dikenali.

app.jsobjek siswa
const siswa = {
  nama: "Alya",
  kelas: "X RPL 1",
  nilai: 88
};

console.log(siswa.nama);
siswa.nilai = 92;

const kunci = "nilai";
console.log(siswa[kunci]);
KEY Cara membacanya
  • nama, kelas, dan nilai adalah nama properti.
  • siswa.nama mengambil properti dengan notasi titik.
  • siswa[kunci] berguna saat nama properti tersimpan di variabel.
  • Nilai properti bisa diperbarui, ditambahkan, atau dibaca.
const menjaga variabel siswa tetap menunjuk ke objek yang sama. Nilai propertinya masih bisa diubah.
Coba: tambahkan properti jurusan, lalu ubah nilai siswa menjadi 95.

Banyak data dengan bentuk serupa

Daftar objek mudah diolah

Gabungkan array dan objek saat ingin menyimpan banyak catatan dengan struktur yang sama.

app.jsfilter dan map
const tugas = [
  { judul: "Navbar", selesai: true },
  { judul: "Kartu produk", selesai: false },
  { judul: "Form kontak", selesai: false }
];

const belumSelesai = tugas.filter(function (item) {
  return !item.selesai;
});

const semuaJudul = tugas.map(function (item) {
  return item.judul;
});
[ ] Dua cara mengolah daftar
  • filter() membuat array baru berisi data yang lolos suatu syarat.
  • map() membuat array baru dari hasil perubahan setiap item.
  • item adalah nama sementara untuk satu objek saat fungsi berjalan.
Di contoh ini, belumSelesai berisi dua tugas. semuaJudul berisi tiga teks judul.
Coba: gunakan filter() untuk mengambil tugas yang sudah selesai.

Format data untuk disimpan dan dikirim

JSON mengubah objek menjadi teks

JavaScript memakai dua fungsi untuk berpindah antara objek dan teks JSON.

app.jsobjek ↔ teks
const siswa = {
  nama: "Alya",
  nilai: 92
};

const teksJson = JSON.stringify(siswa);
console.log(teksJson);
// {"nama":"Alya","nilai":92}

const dataKembali = JSON.parse(teksJson);
console.log(dataKembali.nama);
JSON Ingat pasangan ini
  • JSON.stringify(objek) menghasilkan teks JSON.
  • JSON.parse(teks) membaca teks JSON menjadi nilai JavaScript.
  • JSON cocok untuk data seperti teks, angka, boolean, array, dan objek.
  • JSON tidak menyimpan fungsi.
Teks JSON yang formatnya rusak membuat JSON.parse() menghasilkan error.
Coba: tambahkan properti jurusan, ubah objek ke JSON, lalu parse kembali.

Mengingat data setelah halaman ditutup

localStorage menyimpan data di browser

Simpan JSON sebagai teks, lalu baca kembali saat halaman dibuka.

app.jssimpan dan baca
function simpanTugas(daftarTugas) {
  localStorage.setItem(
    "daftarTugas",
    JSON.stringify(daftarTugas)
  );
}

function bacaTugas() {
  const teks = localStorage.getItem("daftarTugas");
  if (teks === null) return [];
  return JSON.parse(teks);
}

const tugasDimuat = bacaTugas();
// Setelah daftar diubah: simpanTugas(tugasDimuat);
SAVE Tiga operasi dasar
  • setItem(kunci, nilai) menyimpan teks.
  • getItem(kunci) membaca nilai; hasilnya null jika belum ada.
  • removeItem(kunci) menghapus satu data.
  • Data tersimpan untuk halaman dari asal situs yang sama.
Panggil simpanTugas() setelah data berubah. Jangan simpan kata sandi atau data rahasia. Saat halaman dibuka lewat file://, perilaku penyimpanan bisa berbeda; coba lewat server lokal.
Coba: simpan daftar tugas, muat ulang halaman, lalu baca kembali nilainya dari Console.

Mengambil data dari server

fetch() meminta data dari API

API memberi cara bagi halaman web untuk meminta data dari layanan lain.

app.jsPromise dengan then
const alamatApi =
  "https://mdn.github.io/learning-area/javascript/apis/" +
  "fetching-data/can-store/products.json";

fetch(alamatApi)
  .then(function (response) {
    if (!response.ok) {
      throw new Error("HTTP " + response.status);
    }
    return response.json();
  })
  .then(function (data) {
    console.log(data);
  })
  .catch(function (error) {
    console.error("Gagal mengambil data:", error);
  });
API Baca alurnya
  • fetch() meminta alamat API dan menghasilkan Promise.
  • response.ok memeriksa apakah server memberi status sukses.
  • response.json() membaca isi jawaban sebagai data JSON.
  • catch() menangani kegagalan jaringan atau error yang dilempar.
Promise menandai hasil yang akan tersedia setelah proses selesai. fetch() tidak otomatis gagal untuk status 404 atau 500, jadi periksa response.ok. Contoh ini perlu internet, izin CORS, dan sebaiknya dijalankan lewat server lokal.
Amati: buka alamat API di browser untuk melihat teks JSON yang dikirim server.

Menulis kode asinkron dengan alur yang jelas

async dan await membuat kode mudah dibaca

Keduanya membantu menunggu pekerjaan seperti permintaan API tanpa menghentikan seluruh halaman.

app.jsasync/await dan try/catch
async function muatProduk() {
  try {
    const response = await fetch(alamatApi);
    if (!response.ok) {
      throw new Error("HTTP " + response.status);
    }
    const data = await response.json();
    console.log(data);
  } catch (error) {
    console.error("Data gagal dimuat:", error);
  }
}

muatProduk();
WAIT Langkah demi langkah
  • async menandai fungsi yang bekerja dengan Promise.
  • await menunggu hasil fetch() atau response.json().
  • try berisi langkah yang dicoba.
  • catch menjalankan penanganan jika terjadi error.
Dalam file JavaScript biasa, tulis await di dalam fungsi async.
Perhatikan: fungsi ini memakai variabel alamatApi dari contoh sebelumnya. Ubah alamatnya untuk melihat pesan di catch.

Dari jawaban server ke tampilan

Tampilkan status dan isi data

Pengguna perlu tahu apakah data sedang dimuat, berhasil tampil, kosong, atau gagal diambil.

app.jsstatus dan daftar
async function tampilkanProduk() {
  const pesan = document.querySelector("#pesan");
  const daftar = document.querySelector("#daftarProduk");
  pesan.textContent = "Memuat produk...";
  daftar.textContent = "";

  try {
    const response = await fetch(alamatApi);
    if (!response.ok) throw new Error(response.status);
    const data = await response.json();
    if (data.length === 0) {
      pesan.textContent = "Belum ada produk.";
      return;
    }
    data.forEach(function (produk) {
      const item = document.createElement("li");
      item.textContent = produk.name + " — " + produk.type;
      daftar.appendChild(item);
    });
    pesan.textContent = "Produk berhasil dimuat.";
  } catch (error) {
    pesan.textContent = "Data gagal dimuat. Periksa koneksi.";
    console.error(error);
  }
}

tampilkanProduk();
DOM Siapkan elemen HTML
<p id="pesan" aria-live="polite"></p>
<ul id="daftarProduk"></ul>
  • textContent menampilkan teks data dengan aman.
  • createElement() membuat elemen untuk satu produk.
  • aria-live membantu pembaca layar mengetahui status terbaru.
Jangan memasukkan data API langsung ke innerHTML. Buat elemen dan isi teksnya dengan textContent.

Contoh ini memakai variabel alamatApi dari slide permintaan API.
