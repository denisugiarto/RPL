CSS Dasar

HTML menyusun kerangka, CSS yang membuat website terlihat keren. Di sini kamu akan belajar cara mewarnai, mengatur font, dan menyusun tata letak halaman web.

Definisi

Mengatur Tampilan,
bukan struktur.

Cascading Style Sheets

Kumpulan "aturan gaya" (style) yang menentukan bagaimana elemen HTML ditampilkan di browser.

Fokus Visual

Mengatur warna, ukuran huruf, jarak antar elemen, border, dan tata letak (layout) halaman.

Berlapis (Cascading)

Aturan bisa saling menimpa dan diwariskan dari induk ke anak — membuat styling lebih fleksibel.

Cara Menambahkan

3 Cara Menghubungkan CSS

Kamu bisa menulis CSS langsung di elemen, di dalam file HTML, atau di file terpisah. Masing-masing punya kegunaannya sendiri.

Inline Langsung lewat atribut style="" di satu elemen.
<style> Internal — ditulis di dalam tag <style> di bagian <head>.
<link> External — file .css terpisah. Paling rapi & bisa dipakai di banyak halaman. ★ Dianjurkan

style.css + index.html

/* style.css (external) */ h1 { color: #00D9C0; font-size: 40px; } <!-- index.html --> <link rel="stylesheet" href="style.css">
Anatomi Aturan

Bentuk dasar aturan CSS

Setiap aturan CSS terdiri dari tiga bagian: siapa yang dihias (selector), mau diubah apa (property), dan jadi seperti apa (value).

h1 Selector — elemen HTML yang ingin diubah
color Property — bagian yang diubah (mis. warna)
#00D9C0 Value — nilai yang diberikan pada property
h1 { color : #00D9C0 ; }
Selektor

Memilih elemen yang dihias

p — Elemen

Menargetkan semua tag dengan nama yang sama, misalnya semua <p>.

p { color: #9AA5B1; }

Memengaruhi semua paragraf.

.judul — Class

Menargetkan elemen dengan atribut class="judul". Diawali titik (.). Bisa dipakai banyak elemen.

.judul { color: #00D9C0; }

Dipakai berulang-ulang. Paling sering dipakai.

#logo — ID

Menargetkan elemen dengan id="logo". Diawali pagar (#). Harus unik, hanya satu elemen.

#logo { width: 80px; }

Hanya boleh 1 dalam satu halaman.

Satuan Ukuran

Satuan panjang di CSS

px

Pixel

Satuan paling pasti. 1px = 1 titik di layar. Cocok untuk ukuran kecil & border.

font-size: 16px;

%

Persen

Relatif terhadap elemen induknya. Serbaguna untuk lebar yang fleksibel.

width: 50%;

rem

Rem

Relatif terhadap ukuran font di root (<html>). Mudah diubah ukurannya sekaligus.

font-size: 2rem;

vw / vh

Viewport

Relatif terhadap lebar (vw) & tinggi (vh) layar. Bagus untuk halaman penuh.

height: 100vh;

Warna & Latar

Memberi warna halaman

CSS bisa mewarnai teks, latar belakang elemen, bahkan menampilkan gambar sebagai background.

color Warna teks
background-color Warna latar belakang
background-image Gambar sebagai latar
red #00D9C0 rgb(0, 217, 192) → nama, hex, rgb

style.css

h1 { color: #FFD23F; background-color: #161C24; }

Judul Berwarna

Tipografi

Mengatur teks & huruf

font-family Jenis huruf (Arial, Times, dsb.)
font-size Ukuran huruf
font-weight Ketebalan huruf (normal / bold)
text-align Rata teks (kiri, tengah, kanan)
line-height Jarak antar baris

style.css

p { font-family: 'Plus Jakarta Sans'; font-size: 18px; text-align: center; line-height: 1.7; }

Hasil di Browser:

Konsep Kotak

Semua elemen itu kotak

Setiap elemen HTML dianggap sebagai kotak dengan 4 lapisan. Ini fondasi untuk memahami jarak dan tata letak.

1
Content

Isi elemen — teks atau gambar.

2
Padding

Jarak antara isi dan border (ruang napas dalam).

3
Border

Garis pembatas elemen.

4
Margin

Jarak antara elemen ini dengan elemen lain (ruang napas luar).

Jarak

Padding vs Margin

Padding — Jarak Dalam

Ruang di dalam elemen, antara konten dan border. Membuat teks tidak "menempel" pada tepi kotak.

.kartu { padding: 20px; }

Teks punya ruang di dalam kotak.

Margin — Jarak Luar

Ruang di luar elemen, antara elemen satu dengan yang lain. Menciptakan celah antar kartu.

.kartu { margin: 20px; }

Garis Tepi

Border & sudut membulat

Border adalah garis pembatas elemen. Border-radius bisa membuat sudutnya membulat — dari kotak kaku jadi tampilan modern.

border Ketebalan, gaya (solid/dashed/dotted), warna.
border-radius Seberapa bulat sudutnya. 50% = lingkaran penuh.

style.css

button { border: 2px solid #00D9C0; border-radius: 12px; background: transparent; color: #00D9C0; }

Hasil di Browser:

50%
Posisi Elemen

Menggeser posisi elemen

Properti position menentukan bagaimana elemen ditempatkan — termasuk yang bisa "menimpa" elemen lain.

static Default. Mengikuti alur halaman biasa.
relative Bergeser dari posisi aslinya dengan top/left.
absolute Diposisikan relatif terhadap induknya. Bisa menimpa.
fixed Menempel di layar, tidak ikut scroll (mis. navbar).

Pseudo-class

Gaya khusus saat berinteraksi

Pseudo-class menandai elemen dalam kondisi tertentu. Paling populer: :hover — gaya saat kursor di atas elemen.

a:hover Saat kursor menyentuh elemen.
li:first-child Elemen pertama dari induknya.
li:nth-child(2) Elemen ke-2, ke-3, dst. (untuk baris tabel genap/ganjil).

style.css

.demo-btn { background: #1A2229; transition: all .3s; } .demo-btn:hover { background: #00D9C0; transform: translateY(-3px); }

Coba arahkan kursor ke tombol ↓

Layout 1

Mengenal sumbu Flexbox

Flexbox menyusun elemen anak sepanjang satu arah. Arah itu diatur flex-direction — default row (mendatar). Perhatikan urutan angka di tiap contoh di bawah:

display:flex row → kiri ke kanan row-reverse → kanan ke kiri column → atas ke bawah column-reverse → bawah ke atas

Flexbox 4

flex-wrap & gap

Kalau isi terlalu banyak, flex-wrap memutuskan apakah item turun ke baris baru. gap mengatur jarak antar item.

nowrap → satu baris, bisa menyesak wrap → pindah baris saat penuh gap → jarak antar item

flex-wrap: wrap
12345678

gap: 16px
123

Layout 2

Grid — baris & kolom

Kalau Flexbox menyusun satu baris, Grid menyusun dalam baris & kolom sekaligus. Ukuran kolom diatur grid-template-columns:

grid-template-columns: 100px 100px 100px
ukuran tetap per kolom
grid-template-columns: 1fr 1fr 1fr
1fr = bagi rata sisa ruang
grid-template-columns: repeat(3, 1fr)
repeat() = tanpa menulis ulang
grid-template-columns: 1fr 2fr 1fr
fr bisa beda rasio (kolom tengah 2x)
Grid 2

Baris & gap Grid

Selain kolom, kamu juga bisa mengatur tinggi baris dengan grid-template-rows, dan jarak antar sel dengan gap.

grid-template-rows Tinggi tiap baris.
gap: 10px 20px Shorthand — (baris) (kolom).
grid-template-rows: 34px 34px
2 baris dengan tinggi 34px
gap: 12px 24px
jarak antar baris 12px, antar kolom 24px
Grid 3

Galeri auto-fit responsif

Kombinasi repeat(auto-fit, minmax(150px, 1fr)) membuat kolom otomatis menyesuaikan saat layar mengecil — tanpa perlu media query!

style.css

.galeri { display: grid; grid-template-columns: repeat(auto-fit, minmax(150px, 1fr)); gap: 10px; }

Perhatikan beda jumlah kolom saat wadah lebar vs sempit:

Wadah lebar → banyak kolom
Wadah sempit → kolom menyusut & turun
Responsif

Website menyesuaikan semua layar

Media query mengubah gaya saat lebar layar tertentu tercapai — jadi di HP layout menumpuk, di desktop jadi kolom.

@media (max-width: 640px) Aturan aktif saat layar ≤ 640px (HP).
@media (min-width: 1024px) Aturan aktif saat layar ≥ 1024px (desktop).

style.css

.galeri { display: grid; grid-template-columns: repeat(3, 1fr); } @media (max-width: 640px) { .galeri { grid-template-columns: 1fr; } }

Desktop ≥ 1024px

HP ≤ 640px

Gunakan halaman HTML yang sudah kamu buat sebelumnya, lalu percantik dengan semua kemampuan CSS yang sudah dipelajari.

Syarat Wajib:

CSS External

Buat file style.css dan hubungkan dengan <link>.

Warna & Font

Set color, background-color, dan ganti font-family.

Box Model

Terapkan padding, margin, dan border pada kartu profil.

Layout

Susun bagian halaman pakai flexbox atau grid.

Hover

Tombol atau link berubah gaya saat di-hover.

Responsif

Halaman tetap rapi saat dibuka di HP (pakai @media).

Tugas dikumpulkan dalam format:

2 file: tugas_css_nama.html dan tugas_css_nama.css. Pastikan keduanya di folder yang sama dan halaman tampil rapi di browser.
