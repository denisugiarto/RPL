HTML Lanjutan

Siap membawa halaman webmu ke level selanjutnya? Pelajari cara membuat formulir interaktif, tabel data, menyematkan media, dan menyusun struktur web modern menggunakan HTML Semantik.

Formulir Interaktif

Mengumpulkan Data dengan <form>

Formulir adalah cara website untuk "mendengar" input dari user. Digunakan untuk login, pendaftaran, dan mengirim pesan.

<input> Kotak untuk mengetik (teks, email, password).
<label> Judul untuk menjelaskan apa yang harus diketik.
<textarea> Kotak teks panjang untuk paragraf.
<button> Tombol untuk mengirim data.

daftar.html

<form> <label>Nama:</label> <input type="text" placeholder="Budi"> <label>Email:</label> <input type="email" placeholder="budi@email.com"> <label>Password:</label> <input type="password" placeholder="••••••"> <button type="submit">Daftar</button> </form>

Menyusun Data Tabular

Membuat Tabel

Tabel digunakan untuk menampilkan data dalam baris dan kolom, seperti jadwal pelajaran atau daftar nilai.

<table> Wadah utama tabel.
<caption> Judul tabel.
<thead> Table Head — baris judul kolom.
<tbody> Table Body — isi data.
<tfoot> Table Foot — baris ringkasan (total, rata-rata).
<tr> Table Row (Baris).
<th> Table Header (Kepala kolom, teks tebal).
<td> Table Data (Isi sel).
colspan Gabungkan sel yang berdampingan secara horizontal.
rowspan Gabungkan sel ke bawah secara vertikal.
<table> <caption>Daftar Nilai</caption> <thead> <tr> <th>Nama</th> <th>Nilai</th> </tr> </thead> <tbody> <tr> <td>Budi</td> <td>90</td> </tr> </tbody> <tfoot> <tr> <td colspan="2">Rata-rata: 90</td> </tr> </tfoot> </table>

Praktik Penggabungan Sel

Contoh: Jadwal Pelajaran

Tabel jadwal pelajaran sering memiliki sel yang sama di beberapa baris, misalnya nama hari yang sama untuk dua jam pelajaran berurutan. Itu ditangani dengan atribut rowspan.

rowspan="2"

Sel membentang ke bawah sejumlah baris yang ditentukan.

colspan="2"

Sel membentang ke samping sejumlah kolom (sudah kita pelajari).

Tips

Kedua atribut juga bisa digabung dalam satu sel, misal colspan="2" rowspan="2".

jadwal.html

<table> <tr> <th rowspan="2">Senin</th> <td>Matematika</td> </tr> <tr> <td>B. Indonesia</td> </tr> </table>

Media & Embed

Menampilkan Audio, Video & Web Lain

HTML memungkinkan kamu memutar file audio & video langsung atau menyematkan (embed) halaman web lain seperti video YouTube atau Google Maps.

<video>

Memutar video lokal. Gunakan atribut controls agar user bisa play/pause.

<audio>

Memutar file suara seperti musik atau narasi. Sama seperti video, butuh atribut controls.

<iframe>

Menampilkan halaman web lain di dalam websitemu (seperti video YouTube).

media.html

<!-- Audio Lokal --> <audio src="lagu.mp3" controls></audio> <!-- Video Lokal --> <video src="film.mp4" controls></video> <!-- Embed YouTube --> <iframe src="https://youtube.com/..."> </iframe>

Struktur Modern

HTML Semantik

Dulu, orang pakai <div> untuk semua hal. Sekarang, HTML5 punya tag yang "bermakna" (semantik) untuk membantu browser & mesin pencari memahami struktur halaman.

<header>
<nav>
<main>
<aside>
<footer>
SEO Lebih Baik

Google lebih mudah membaca kontenmu karena strukturnya jelas.

Aksesibilitas

Screen reader untuk tuna netra bisa menavigasi halaman dengan lebih baik.

Kode Lebih Rapi

Lebih mudah dibaca programmer lain (atau dirimu sendiri di masa depan).

Bagian Tak Terlihat

Metadata di <head>

Tag <head> berisi informasi tentang dokumen yang tidak tampil di badan browser, tapi sangat penting untuk browser dan SEO.

<meta charset> Agar teks (huruf) tampil dengan benar.
<meta viewport> Membuat web responsif di HP.
<title> Judul halaman & nama yang muncul di tab browser.
<meta description> Deskripsi singkat untuk Google.

Kenapa Penting?

Ranking di Google (SEO)

Judul (<title>) & deskripsi menentukan apakah situsmu tampil di hasil pencarian.

Tampilan saat di-share

Tanpa meta description, WhatsApp/Instagram hanya menampilkan URL mentah yang tidak menarik.

Tampil rapi di HP

Tanpa meta viewport, halamanmu tampil kecil dan sulit dibaca di ponsel.

head.html

<head> <meta charset="UTF-8"> <meta name="viewport" content="width=device-width, initial-scale=1.0"> <title>Toko Sepatu Maju</title> <meta name="description" content="Jual sepatu original."> </head>
Katalog <head>

Tag yang Bisa di <head>

Anggap <head> sebagai "ruang pengaturan". Tag dikelompokkan per tugas biar mudah diingat.

Wajib di Setiap Halaman

<meta charset>Biar huruf & emoji benar.
<meta viewport>Responsif di HP.
<title>Judul di tab & Google.

SEO & Saat Di-share

<meta description>Ringkasan buat Google.
og:title, og:image, …Pratinjau menarik saat di-share.
<meta name="author">Nama pembuat.

Tampilan (CSS)

<link rel="stylesheet">File CSS eksternal.
<style>CSS ditulis langsung.
<meta name="theme-color">Warna bar di HP.

Interaksi, Koneksi & Identitas

<script src>File JavaScript (interaksi).

Script & CSS

Script & Style di <head>

Tidak semua script boleh di <head>. Ingat aturan kecepatan loading agar halaman cepat tampil.

Script yang aman di <head>

Yang tidak menyentuh elemen (analytics, konfigurasi) atau yang memakai defer / async.

Hindari: tanpa defer

Script biasa memblokir tampilan. Simpan di akhir <body> atau pakai defer.

<style> di <head>

CSS internal ditulis di sini, sebelum konten — cegah "blink" tanpa gaya saat load.

Alternatif: file terpisah

<link rel="stylesheet"> untuk aturan yang banyak & dipakai ulang.

pola yang DIANJURKAN:

<head> <link rel="stylesheet" href="style.css"> <script src="app.js" defer></script> </head> <body> <!-- konten halaman --> <script src="lazy.js"></script> </body>
Melengkapi HTML

Mempercantik dengan CSS

HTML menyusun isi halaman, CSS menentukan tampilannya — warna, ukuran huruf, hingga tata letak.

Inline CSS ditulis langsung lewat atribut style="".
<style> Internal — CSS dalam satu tag <style> di <head>.
<link rel="stylesheet"> External — file .css terpisah, paling rapi & bisa dipakai ulang. ★ Dianjurkan

style.css + cara pakai

/* style.css (external) */ h1 { color: #FF6B35; font-size: 32px; } p { color: #9AA5B1; } <link rel="stylesheet" href="style.css">
Pratinjau di Media Sosial

Open Graph — Detail

Open Graph menentukan tampilan preview saat link kamu di-share di WhatsApp, Instagram, atau Facebook — bukan sekadar URL mentah.

og:title Judul besar yang tampil di pratinjau.
og:description Ringkasan singkat di bawah judul.
og:image Gambar pratinjau (disarankan 1200×630).
og:url Link asli, agar tidak terjadi tautan ganda.
og:type Jenis konten: website, article, video, dll.
og:locale Bahasa konten, mis. id_ID.

Contoh og: di <head>

<meta property="og:title" content="Toko Sepatu Maju"> <meta property="og:description" content="Jual sepatu original."> <meta property="og:image" content="https://…/sepatu.jpg"> <meta property="og:url" content="https://…/"> <meta property="og:type" content="website">
