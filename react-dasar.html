Sambungkan dengan bekal JavaScript

Kenali datanya, lalu bangun tampilannya

React akan terasa lebih mudah setelah kamu memahami fungsi, array, objek, event, dan pengambilan data.

JS Prasyarat
  • HTML dan CSS sederhana.
  • Variabel, fungsi, objek, dan array.
  • Event, form, dan perubahan tampilan dengan DOM.
  • Dasar Promise, fetch(), dan async/await.
GOAL Setelah belajar
  • Membagi halaman menjadi komponen.
  • Mengirim data melalui props dan mengubah tampilan dengan state.
  • Membuat pencarian dan daftar data dari API.
  • Menyusun proyek katalog sederhana.
Siapkan: VS Code, Node.js dengan npm, dan browser modern. Proyek React dijalankan lewat server pengembangan, bukan dengan membuka file JSX langsung.

Siapkan lingkungan latihan

Buat proyek React dengan Vite

Vite menyiapkan server lokal dan alat untuk mengubah JSX menjadi kode yang dapat dijalankan browser.

Terminaljalankan berurutan
npm create vite@latest katalog-kelas -- --template react
cd katalog-kelas
npm install
npm run dev
RUN Setelah server hidup
  1. Buka alamat lokal yang muncul di Terminal.
  2. File utama latihan ada di src/App.jsx.
  3. Simpan perubahan; browser akan memperbarui tampilan.
Pastikan Node.js dan npm terpasang. Jika perintah gagal, periksa versi Node yang disyaratkan oleh versi Vite yang digunakan.
Catatan guru: Vite dipakai agar siswa fokus pada dasar React. Proyek React yang berkembang dapat memakai framework dengan fitur yang lebih lengkap.

HTML-like syntax di JavaScript

JSX menuliskan tampilan

JSX terlihat seperti HTML, tetapi dapat memakai ekspresi JavaScript di dalam kurung kurawal.

App.jsxJSX
const nama = "Alya";

function Sambutan() {
  return (
    <section className="kartu">
      <h1>Halo, {nama}!</h1>
      <p>Selamat belajar React.</p>
    </section>
  );
}
JSX Perhatikan aturan ini
  • Gunakan className untuk memberi class CSS.
  • Tulis ekspresi JavaScript di antara { }.
  • Elemen yang tidak punya isi ditutup, misalnya <img />.
  • JSX dalam return harus punya satu elemen induk.
Ubah: ganti nama, teks sambutan, dan nama class, lalu simpan.

Satu fungsi, satu bagian tampilan

Komponen React adalah fungsi

Nama komponen diawali huruf besar. Komponen mengembalikan JSX yang ingin ditampilkan.

src/App.jsxkomponen pertama
function Judul() {
  return <h1>Katalog Barang</h1>;
}

function App() {
  return (
    <main>
      <Judul />
    </main>
  );
}

export default App;
APP Bacalah dari atas
  • Judul menggambar judul halaman.
  • <Judul /> memakai komponen sebagai elemen JSX.
  • App menggabungkan bagian halaman.
  • export default menyediakan komponen utama untuk file lain.
Coba: buat komponen Footer lalu tampilkan di bawah Judul.

Komponen yang bisa dipakai ulang

Props memberi komponen data

Komponen induk mengirim nilai ke komponen anak melalui atribut JSX yang disebut props.

ProductCard.jsxmenerima props
function ProductCard({ nama, kategori }) {
  return (
    <article className="produk">
      <h2>{nama}</h2>
      <p>Kategori: {kategori}</p>
    </article>
  );
}

<ProductCard
  nama="Roti tawar"
  kategori="Makanan"
/>
DATA Props itu seperti argumen
  • nama dan kategori adalah props.
  • Props bisa berisi teks, angka, array, objek, atau fungsi.
  • Komponen menerima props dan menggunakannya untuk merender UI.
  • Anggap props sebagai data baca-saja; perubahan data dikelola oleh induk.

Dari array ke elemen antarmuka

map() membuat daftar UI

Array barang dapat diubah menjadi kumpulan komponen yang punya bentuk seragam.

App.jsxdaftar produk
const produk = [
  { id: 1, nama: "Roti" },
  { id: 2, nama: "Susu" }
];

function DaftarProduk() {
  return (
    <ul>
      {produk.map((item) => (
        <li key={item.id}>{item.nama}</li>
      ))}
    </ul>
  );
}
KEY Mengapa ada key?
  • map() memanggil fungsi untuk setiap item.
  • key membantu React mengenali item yang berubah.
  • Pilih nilai yang unik dan tetap, seperti id.
  • Jangan gunakan posisi array sebagai key jika daftar bisa berubah urutannya.

Tanggapi tindakan pengguna

Event menghubungkan klik dengan aksi

Kirim fungsi sebagai event handler. React akan menjalankannya saat pengguna berinteraksi.

ProductCard.jsxevent onClick
function ProductCard({ nama, onPilih }) {
  return (
    <article>
      <h2>{nama}</h2>
      <button
        type="button"
        onClick={onPilih}
      >
        Pilih
      </button>
    </article>
  );
}
EVENT Huruf besar-kecil penting
  • Nama event React memakai camelCase: onClick.
  • Nilainya fungsi: onClick={onPilih}.
  • Jangan langsung memanggilnya: onClick={onPilih()}.
  • Props onPilih membolehkan komponen anak memberi tahu induknya.
Coba: buat tombol yang memanggil alert("Dipilih") melalui fungsi bernama.

Data yang berubah saat aplikasi dipakai

useState mengingat perubahan

State menyimpan data milik komponen. Memanggil fungsi setter meminta React merender tampilan terbaru.

Counter.jsxstate angka
import { useState } from "react";

function Counter() {
  const [jumlah, setJumlah] = useState(0);

  return (
    <button onClick={() => setJumlah(jumlah + 1)}>
      Dipilih {jumlah} kali
    </button>
  );
}
STATE Dua bagian state
  • jumlah adalah nilai saat ini.
  • setJumlah meminta React mengganti nilainya.
  • useState(0) menentukan nilai awal.
  • Jangan mengubah state langsung dengan jumlah++.
Panggil Hook seperti useState di bagian atas fungsi komponen, bukan di dalam kondisi atau perulangan.

State yang berisi daftar

Buat array baru saat favorit berubah

Jangan mengubah array state langsung. Buat array baru dengan spread, filter(), atau map().

App.jsxtambah atau hapus favorit
function App({ produk }) {
  const [favorit, setFavorit] = useState([]);

  function ubahFavorit(id) {
    setFavorit((current) =>
      current.includes(id)
        ? current.filter((item) => item !== id)
        : [...current, id]
    );
  }

  return <ProductList items={produk} onToggle={ubahFavorit} />;
}
ARRAY Salin, lalu perbarui
  • current adalah nilai state terbaru.
  • filter() membuat array baru tanpa barang yang dihapus.
  • [...current, id] membuat array baru dengan barang tambahan.
  • Fungsi setter menjaga perubahan state terbaca oleh React.
Sambungkan: panggil ubahFavorit(product.name) dari event tombol kartu barang.

Hubungkan form ke state

Input terkontrol membuat pencarian responsif

Nilai input berasal dari state. Saat pengguna mengetik, event memperbarui state.

App.jsxinput dan filter
function App({ produk }) {
  const [cari, setCari] = useState("");
  const hasil = produk.filter((item) =>
    item.name.toLowerCase().includes(cari.toLowerCase())
  );

  return (
    <>
      <label>
        Cari barang
        <input
          value={cari}
          onChange={(event) => setCari(event.target.value)}
        />
      </label>
      <DaftarProduk items={hasil} />
    </>
  );
}
INPUT Satu sumber nilai
  • value={cari} menampilkan nilai state pada input.
  • onChange mengambil teks yang baru diketik.
  • filter() menghasilkan daftar hasil pencarian.
  • Nilai hasil bisa dihitung langsung dari state; tidak perlu disimpan sebagai state kedua.
Ingat: untuk pencarian tanpa membedakan huruf besar dan kecil, ubah teks dan kata pencarian menjadi huruf kecil.

Beritahu pengguna apa yang sedang terjadi

Tampilan berbeda mengikuti keadaan data

Data belum selesai dimuat, gagal, atau tidak ditemukan? Tampilkan pesan yang sesuai.

ProductResults.jsxkondisi
if (memuat) {
  return <p>Memuat barang...</p>;
}

if (error) {
  return <p role="alert">{error}</p>;
}

if (hasil.length === 0) {
  return <p>Barang tidak ditemukan.</p>;
}

return <DaftarProduk items={hasil} />;
UI Empat keadaan dasar
  • Memuat: proses pengambilan data berlangsung.
  • Gagal: tampilkan pesan dan cara mencoba lagi.
  • Kosong: pencarian tidak menemukan barang.
  • Berhasil: tampilkan daftar barang.

Sinkronkan komponen dengan layanan luar

useEffect menjalankan fetch

Contoh ini meminta daftar barang saat komponen dipasang, lalu menyimpan hasilnya dalam state.

App.jsxpermintaan API
import { useEffect, useState } from "react";

const alamatApi =
  "https://mdn.github.io/learning-area/javascript/apis/fetching-data/can-store/products.json";

function App() {
  const [produk, setProduk] = useState([]);
  const [memuat, setMemuat] = useState(true);
  const [error, setError] = useState("");

  useEffect(() => {
    const controller = new AbortController();
    async function muatProduk() {
      try {
        const response = await fetch(alamatApi, {
          signal: controller.signal
        });
        if (!response.ok) throw new Error();
        setProduk(await response.json());
      } catch {
        if (!controller.signal.aborted) {
          setError("Barang gagal dimuat.");
        }
      } finally {
        if (!controller.signal.aborted) setMemuat(false);
      }
    }

    muatProduk();
    return () => controller.abort();
  }, []);

  return (
    <ProductResults products={produk} loading={memuat} error={error} />
  );
}
WAIT Alur permintaan
  • useEffect menjalankan proses setelah tampilan dirender.
  • [] berarti Effect ini tidak bergantung pada props atau state lain.
  • response.ok memastikan status HTTP sukses.
  • AbortController membatalkan permintaan saat komponen dilepas.
Ini pola latihan untuk memahami Effect. Aplikasi yang lebih besar bisa memakai mekanisme data dari framework atau pustaka cache.
Contoh API: MDN Can Store products. Jalankan dari proyek lokal dan pastikan koneksi internet aktif.

Gabungkan props dan daftar

Satu data barang menjadi satu kartu

Komponen kartu menerima satu objek. Komponen daftar membuat kartu untuk setiap barang.

ProductList.jsxkartu dari data API
function ProductCard({ product, onPilih }) {
  return (
    <article className="produk">
      <h2>{product.name}</h2>
      <p>Kategori: {product.type}</p>
      <p>Harga: ${product.price.toFixed(2)}</p>
      <button onClick={onPilih}>Simpan favorit</button>
    </article>
  );
}

function ProductList({ items, onToggle }) {
  return items.map((product) => (
    <ProductCard
      key={product.name}
      product={product}
      onPilih={() => onToggle(product.name)}
    />
  ));
}
CARD Bagian yang saling terhubung
  • ProductList menerima array melalui props items.
  • ProductCard menerima objek melalui props product.
  • key memakai nama unik yang tersedia pada data contoh MDN.
  • Jika API lain menyediakan id, gunakan id sebagai key.
Format harga: contoh memakai angka dolar dari data latihan. Sesuaikan mata uang jika memakai data lain.
