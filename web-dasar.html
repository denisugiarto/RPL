Modul Pembelajaran Web Front-End

HTML, CSS, & JavaScript

Tiga bahasa ini adalah fondasi dari setiap website di dunia. Pelajari peran masing-masing, dan kamu siap membangun apapun di internet.

Analogi Dasar

Website itu seperti membangun rumah.

HTML = Pondasi & Tembok

Tanpa HTML, rumah tidak berdiri. Ia menentukan ada berapa kamar, pintu, dan jendela. Tapi rumahnya masih polos tanpa cat.

CSS = Cat & Interior

CSS mengecat tembok, mengatur tata letak furniture, dan membuat rumah terlihat indah. Tanpa CSS, websitemu terlihat seperti di tahun 1990-an.

JS = Listrik & Ledeng

Saklar lampu menyala saat ditekan, air mengalir saat keran dibuka. JavaScript membuat websitemu "hidup" dan bisa berinteraksi dengan pengguna.

HTML

HyperText Markup Language

Bahasa untuk membangun struktur halaman web. Bukan bahasa pemrograman, melainkan bahasa markah (markup). Menggunakan "tag" untuk membungkus teks.

  • Menentukan judul, paragraf, gambar, dan link.
  • Tidak peduli tentang warna atau ukuran (itu tugas CSS).
  • Tidak bisa berhitung atau logika (itu tugas JS).

index.html

<h1>Toko Sepatu Maju Jaya</h1> <p>Jual sepatu original.</p> <button>Beli Sekarang</button>

↑ Struktur dasar tanpa gaya.

CSS

Cascading Style Sheets

Bahasa untuk mendandani tampilan struktur HTML. Mengatur warna, font, layout (tata letak), animasi, dan responsivitas di HP.

  • Membuat tombol jadi bulat, teks jadi biru, dll.
  • Bisa mengatur layout kompleks seperti Flexbox & Grid.
  • Memisahkan konten (HTML) dengan tampilan visual.

style.css

h1 { color: #FF6B35; font-size: 40px; } button { background: #00D9C0; border-radius: 12px; }

↑ Tombol jadi bulat, Judul jadi oranye.

JS

JavaScript

Bahasa pemrograman yang membuat website interaktif & dinamis. Dia bisa berpikir, menghitung, dan merespon apa yang dilakukan user.

  • Mengubah teks saat tombol diklik.
  • Mengambil data dari server (API).
  • Membuat game, kalkulator, validasi form login.

script.js

const tombol = document.querySelector('button'); tombol.addEventListener('click', () => { alert('Terima kasih sudah beli!'); });

↑ Saat tombol diklik, muncul pop-up.

Urutan Eksekusi di Browser

Ketika kamu membuka sebuah website, browser membaca kodenya dengan urutan ini:

1

Membaca HTML

Browser membangun struktur pohon DOM (Document Object Model).

2

Menerapkan CSS

Browser mewarnai dan menyusun layout berdasarkan aturan CSS.

3

Menjalankan JS

JavaScript dieksekusi untuk menambahkan event listener, logika, dll.

Misimu: Buat Kartu Profil Interaktif

Buatlah halaman web sederhana berisi kartu profil (biodata) dirimu sendiri lengkap dengan HTML, CSS, dan JavaScript.

1. HTML Struktur

  • • Foto profil (tag img)
  • • Nama & deskripsi (h1, p)
  • • Tombol "Follow" (button)

2. CSS Desain

  • • Desain kartu di tengah layar
  • • Tambahkan border-radius & shadow
  • • Beri warna sesuai tema favoritmu

3. JS Interaktif

  • • Saat tombol diklik, muncul alert
  • • Buat angka follower bertambah +1
  • • (Opsional) Ubah warna teks saat di-hover

Yang Dikumpulkan:

Kirim 1 file HTML (kamu bisa gabungkan CSS & JS di dalamnya dengan tag <style> dan <script>), atau kirim 3 file terpisah dalam 1 folder ZIP.
