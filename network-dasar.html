01 // Network

Apa itu Jaringan Komputer?

Jaringan (network) adalah dua atau lebih komputer yang saling terhubung untuk berbagi data dan sumber daya.

Kenapa komputer butuh jaringan?

💬 Berkomunikasi — chat, email, video call

📂 Berbagi file — antar komputer/printer

🌐 Akses internet — masalah data, media, dst.

🤝 Kolaborasi — main game online, kerja tim

Pengertian singkat
# Network = kumpulan perangkat saling
# terhubung agar bisa bertukar data.
Komputer A ──┐
Komputer B ──┤ hub ─Internet
Printer ──┘
# Jenis berdasarkan ukuran:
LAN (skala kecil, satu ruangan)
WAN / Internet (skala dunia)
💡 ANALOGI

Jaringan itu seperti gang yang menghubungkan rumah-rumah tetangga.
Setiap rumah (komputer) punya nomor sendiri (IP). Ada gang kecil (LAN) dan jalan raya antar kota (Internet). Supaya surat bisa diterima alamat yang benar, butuh aturan tertentu pula.

02 // Protocol

Apa itu Protocol?

Protocol adalah aturan dan standar yang menentukan bagaimana data dikirim, diterima, dan diformat di jaringan.

Aturan Bahasa Bersama

Semua perangkat harus "berbahasa sama" agar data bisa dipahami. Protocol inilah kamusnya.

Standar Dunia

Protocol dipakai di seluruh dunia, jadi perangkat brand apa pun bisa saling terhubung.

Tata Cara Komunikasi

Mengatur cara mulai, isi, dan mengakhiri komunikasi data antar perangkat.

protocol yang sering kamu temui
IP (alamat perangkat)
TCP (kirim pasti sampai)
UDP (kirim cepat, tak dijamin)
HTTP (web biasa)
HTTPS (web aman)
DNS (mengolah nama)
📬 ANALOGI

Protocol = aturan mengirim surat.
Ada aturan: tulis alamat tujuan, tulis pengirim, pakai amplop, beri perangko. Semua pengirim & penerima sepakat dengan aturan ini sehingga surat sampai dengan benar. Protocol jaringan melakukan hal yang sama untuk data.

03 // IP Address

Alamat IP Address

IP (Internet Protocol) Address adalah nomor unik yang mengidentifikasi perangkat di jaringan, seperti alamat rumah untuk komputer.

terminal — cek IP kamu
# Windows (CMD / PowerShell)
C:\> ipconfig
IPv4 Address: 192.168.1.5
# Mac / Linux
$ ifconfig
inet 192.168.1.5 netmask ...
# IP publik kamu
$ curl ifconfig.me
203.0.113.45

IPv4

192.168.1.5

4 kelompok angka (0-255) dipisah titik. Yang paling umum dipakai.

≈ 4 miliar alamat

IPv6

2001:0db8:...

Format panjang basis hexadesimal. Untuk kebutuhan alamat masif masa depan.

≈ hampir tak terbatas

🏠 IP Private = di dalam jaringan rumah/kantor (contoh 192.168.x.x).
🌍 IP Public = identitas perangkat di internet besar (tunggal di dunia).
🏠 ANALOGI

IP = nomor rumah. Setiap perangkat punya alamat unik. Pos (data) bisa dikirim ke alamat yang benar. Karena itu, tidak boleh ada dua perangkat dengan IP yang sama di jaringan yang sama.

04 // Domain

Apa itu Domain?

Domain adalah nama yang mudah diingat untuk sebuah IP address, yang menggantikan deretan angka yang sulit dihafal.

https://www.belanja.com/
https:// → protocol
www → subdomain (optional)
belanja → nama domain
.com → TLD (ekstensi)

Bandingkan: lebih mudah mengingat belanja.com daripada 203.0.113.45, bukan? Domain membuat browsing jadi ramah untuk manusia.

🌐

.com

komersial

🌐

.id

Indonesia

🌐

.org

organisasi

📒 ANALOGI

Domain = nama toko, IP = alamat toko.
Kalau kamu bilang "ke Toko Sumber Jaya" (domain), semua orang paham. Tapi sebenarnya kamu perlu alamat jalan & nomor rumah (IP) untuk menuju kesana. DNS yang menghubungkan keduanya.

05 // DNS

Apa itu DNS?

DNS (Domain Name System) adalah sistem yang menerjemahkan nama domain menjadi IP address.

1
Kamu ketik domain

Contoh: kamu ketik belanja.com di browser.

2
DNS mencarikan IP

DNS server mencari IP address untuk domain itu, contoh 203.0.113.45.

3
Browser terhubung ke IP

Browser menuju server dengan alamat IP itu dan memuat halaman website.

4
Halaman tampil!

Semua terjadi dalam hitungan mili-detik tanpa kamu sadari.

visual — proses DNS
Browser
│ "belanja.com?"
▼
DNS Server
│ "IP-nya 203.0.113.45"
▼
Server 203.0.113.45
Belanja.com = hasilnya
≡ halaman web ditampilkan 👍
📞 ANALOGI

DNS = buku kontak / direktori telepon.
Di kontak kamu menyimpan "Ibu" yang terhubung ke nomor 0812-3456-7890. Kamu cukup bilang menelepon "Ibu", dan kontak itu yang mengenal nomor aslinya. DNS bekerja persis seperti itu untuk domain → IP.

06 // HTTP

HTTP - Bahas Server

HTTP (HyperText Transfer Protocol) adalah protocol untuk memindahkan halaman web antara server dan browser.

Apa yang dilakukan HTTP?

1️⃣ Browser mengirim permintaan (request)

2️⃣ Server mengirim jawaban (response) berisi halaman

3️⃣ Browser menampilkan hasil ke kamu

⚠️ Sayangnya, HTTP mengirim data tanpa enkripsi — rawan dibaca orang lain.

HTTP request & response
// Permintaan (Request):
GET /produk HTTP/1.1
Host: belanja.com
// Jawaban (Response):
HTTP/1.1 200 OK
Content-Type: text/html
[kode HTML halaman...]
// Status code populer:
200 OK • 404 Not Found • 500 Server Error
07 // HTTPS

HTTPS - Versi Aman

HTTPS (HTTP Secure) adalah versi HTTP yang data-nya dienkripsi, sehingga aman dibaca orang lain yang tidak berhak.

Mengapa HTTPS lebih aman?

🔒 Data dienkripsi/dikodekan

🛡️ Memakai TLS/SSL untuk keamanan

✅ Menjaga data sensitif (password, kartu, dll)

🔍 Browser menandai kunci gembok di address

🔓

http://

Data mengalir polos / plaintext. Rawan dibaca atau diintip pihak lain.

🔒

https://

Data dienkripsi. Aman dari penyusup. Standar wajib website modern.

⚠️ TANDA AMAN: Selalu cek di address browser. Kalau ada ikn 🔒 + dimulai dengan https://, berarti tampilan kamu aman. Jangan memasukkan data pribadi di website yang hanya http://.
08 // Perbandingan

HTTP vs HTTPS

Mari bandingkan langsung perbedaan keduanya secara ringkas.

tabel perbandingan
Aspek HTTP HTTPS
Kependekan HyperText Transfer Protocol + Secure (aman)
Enkripsi Tidak ada Ada (TLS/SSL)
Port default 80 443
Kecepatan Tanpa overhead enkripsi Tersikret ringan (sekarang setara)
Kegunaan ❌ Tidak disarankan ✅ Standar semua website
💌 ANALOGI

HTTP = surat biasa di kertas, HTTPS = surat dalam kotak terkunci.
Kalau kamu kirim surat HTTP, siapa pun yang mengambil bisa membacanya. Dengan HTTPS, isinya dikunci dan hanya penerima (server) yang punya kuncinya untuk membuka.
