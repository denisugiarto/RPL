Perintah terminal siap pakai

Cari perintah yang dibutuhkan, lihat contoh, lalu ganti nama folder atau proyek sesuai latihanmu.

Catatan: Jangan ketik tanda prompt seperti $ di awal contoh. Jalankan perintah dari folder proyek yang benar.

Linux dan Bash

Perintah dasar untuk terminal Linux/macOS dengan shell Bash.

  • pwdMelihat lokasi folder saat ini.
  • ls -laMelihat semua file, termasuk file tersembunyi.
  • cd nama-folderMasuk ke folder.
  • cd ..Naik satu tingkat folder.
  • mkdir -p src/componentsMembuat folder bertingkat sekaligus.
  • touch app.jsMembuat file kosong atau memperbarui waktu file.
  • cat app.jsMenampilkan isi file teks.
  • less app.jsMembaca file panjang per halaman; tekan q untuk keluar.
  • cp app.js salinan.jsMenyalin file.
  • cp -r src backup-srcMenyalin folder beserta isinya.
  • mv app.js src/app.jsMemindahkan atau mengganti nama file.
  • rm -i app.jsMenghapus file setelah meminta konfirmasi.
  • find . -name "*.js"Mencari file JavaScript di folder proyek.
  • grep -R "TODO" srcMencari teks di file dalam folder src.
  • code .Membuka folder saat ini di VS Code jika perintah tersedia.
  • clearMembersihkan tampilan terminal.

Jika nama file atau folder berisi spasi, gunakan tanda kutip, misalnya cd "Proyek RPL". Hindari rm -rf karena dapat menghapus banyak file tanpa konfirmasi.

Node.js dan npm

Jalankan dari folder proyek yang berisi package.json.

  • node --versionMemeriksa versi Node.js.
  • npm --versionMemeriksa versi npm.
  • nodeMembuka mode interaktif Node.js; ketik .exit untuk keluar.
  • node app.jsMenjalankan file JavaScript dengan Node.js.
  • npm init -yMembuat package.json dengan pengaturan awal.
  • npm installMemasang dependensi yang tercatat dalam proyek.
  • npm install nama-paketMenambahkan paket sebagai dependensi proyek.
  • npm install -D nama-paketMenambahkan paket untuk kebutuhan pengembangan.
  • npm uninstall nama-paketMenghapus paket dari proyek.
  • npm runMelihat script yang tersedia dalam package.json.
  • npm run devMenjalankan server pengembangan jika script tersedia.
  • npm startMenjalankan script start jika tersedia.
  • npm run buildMembuat hasil build jika script tersedia.
  • npm listMelihat paket yang terpasang di proyek.
  • npm outdatedMemeriksa paket yang memiliki versi lebih baru.
  • Ctrl + CMenghentikan server atau proses yang sedang berjalan.

Git

Alur umum: siapkan repositori, simpan perubahan, lalu bagikan ke remote seperti GitHub.

Konfigurasi dan repositori

  • git --versionMemeriksa instalasi Git.
  • git config --global user.name "Nama Kamu"Mengatur nama pada commit.
  • git config --global user.email "kamu@example.com"Mengatur email pada commit.
  • git config --listMelihat konfigurasi Git yang aktif.
  • git initMembuat repositori Git di folder saat ini.
  • git clone URL-repositoriMengunduh salinan repositori.

Simpan perubahan

  • git statusMelihat file yang berubah dan branch aktif.
  • git add app.jsMemilih satu file untuk commit.
  • git add .Memilih perubahan di folder saat ini.
  • git diffMelihat perubahan yang belum masuk staging.
  • git diff --stagedMeninjau perubahan yang siap di-commit.
  • git commit -m "tambah fitur"Menyimpan staging ke riwayat Git.
  • git log --onelineMelihat ringkasan riwayat commit.

Branch dan kolaborasi

  • git branchMelihat daftar branch lokal.
  • git switch -c fitur/nama-fiturMembuat branch dan langsung berpindah.
  • git switch mainBerpindah ke branch main.
  • git remote -vMelihat alamat remote yang terhubung.
  • git fetch originMengambil informasi terbaru tanpa menggabungkan perubahan.
  • git pullMengambil dan menggabungkan perubahan dari remote.
  • git push -u origin nama-branchMengirim branch pertama kali ke remote.

Batalkan dengan hati-hati

  • git restore --staged app.jsMengeluarkan file dari staging tanpa menghapus isinya.
  • git restore app.jsMengembalikan perubahan file yang belum di-commit; perubahan itu hilang.
  • git revert HASHMembatalkan commit dengan membuat commit baru.
  • git stashMenyimpan sementara perubahan yang belum di-commit.
  • git stash popMengembalikan perubahan yang disimpan sementara.

Jangan gunakan git reset --hard tanpa memahami dampaknya karena perubahan lokal dapat terhapus.

Docker dan Docker Compose

Docker CLI mengelola image dan container. Compose menjalankan beberapa layanan dari file konfigurasi proyek.

Image dan container

  • docker --versionMemeriksa versi Docker CLI.
  • docker infoMemeriksa koneksi ke Docker Engine.
  • docker pull nginxMengunduh image dari registry.
  • docker imagesMelihat image yang tersedia di komputer.
  • docker build -t web-rpl:1.0 .Membangun image dari Dockerfile di folder saat ini.
  • docker run -d --name web-rpl -p 8080:80 nginxMembuat container latar belakang dan membuka port 8080.
  • docker psMelihat container yang sedang berjalan.
  • docker ps -aMelihat semua container, termasuk yang berhenti.

Periksa dan kelola container

  • docker logs -f web-rplMengikuti log container; tekan Ctrl + C untuk berhenti melihat.
  • docker exec -it web-rpl shMembuka shell di dalam container yang berjalan.
  • docker inspect web-rplMelihat detail konfigurasi container.
  • docker statsMelihat penggunaan sumber daya container.
  • docker stop web-rplMenghentikan container dengan aman.
  • docker start web-rplMenjalankan kembali container yang berhenti.
  • docker rm web-rplMenghapus container yang sudah berhenti.
  • docker rmi web-rpl:1.0Menghapus image jika tidak sedang dipakai container.

Docker Compose

  • docker compose versionMemeriksa versi Docker Compose.
  • docker compose up --buildMembangun image dan menjalankan layanan di terminal ini.
  • docker compose up -d --buildMenjalankan layanan di latar belakang.
  • docker compose psMelihat status layanan proyek.
  • docker compose logs -fMengikuti log semua layanan.
  • docker compose exec web shMembuka shell di layanan bernama web.
  • docker compose restart webMemulai ulang layanan web.
  • docker compose downMenghentikan dan menghapus container serta jaringan proyek.

Jaga data dan ruang disk

  • docker system dfMelihat pemakaian ruang disk Docker.
  • docker image pruneMenghapus image tak terpakai yang menggantung.
Perhatian: docker compose down -v menghapus volume proyek dan dapat menghilangkan data database. Perintah pembersihan seperti docker system prune juga bisa menghapus resource yang masih ingin dipakai. Tinjau target dan cadangkan data terlebih dahulu.

Kebiasaan aman

Biasakan memeriksa konteks sebelum menjalankan perintah.

Cek lokasi dan perubahan

Sebelum menghapus atau memindahkan file, periksa folder dengan pwd, lalu tinjau perubahan Git dengan git status.

Lindungi rahasia

Jangan unggah kata sandi, token, atau file .env ke GitHub. Pastikan file rahasia masuk ke .gitignore.
