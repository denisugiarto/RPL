Kaskade

Siapa yang menang?

Saat dua aturan menabrak elemen yang sama, browser memakai aturan dengan spesifisitas paling tinggi.

Inline style paling kuat
#id Kedua
.class Ketiga
elemen Terlemah
💡 Kalau spesifisitas sama, aturan yang ditulis paling akhir yang menang.

skor spesifisitas (id, class, elemen)

p { color: red } → (0, 0, 1) 1 elemen
.judul { color: blue } → (0, 1, 0) 1 class — mengalahkan elemen
#nama { color: green } → (1, 0, 0) 1 id — mengalahkan class
style="..." → (1, 0, 0, 0) inline — selalu menang

Variabel CSS

Simpan nilai sekali, pakai berkali-kali. Ganti di satu titik, semua berubah — inilah rahasia deck tema yang rapi.

--warna Definisi variabel, diawali dua tanda --.
var(--warna) Memakai nilai variabel di property manapun.
var(--warna, #333) Nilai cadangan (fallback) jika variabel belum ada.

:root — deklarasi global

:root { --warna-utama: #FF4D8D; --radius: 16px; } .tombol { background: var(--warna-utama); border-radius: var(--radius); }

Bayangkan: ubah 1 baris → seluruh website berganti tema.

Selektor Lanjut 1

Selektor kombinator

Menembak elemen berdasarkan hubungannya dengan elemen lain.

nav p

Turunan — semua <p> di dalam <nav>, seberapa dalam pun.

nav p { color: #9AA5B1; }

ul > li

Anak langsung — > hanya level satu di bawah.

ul > li { margin: 8px 0; }

h1 + p

Saudara terdekat — <p> tepat setelah <h1>.

h1 + p { font-size: 18px; }

h1 ~ p

Semua saudara setelah — semua <p> setelah h1.

h1 ~ p { line-height: 1.6; }
Selektor Lanjut 2

Selektor atribut

Menembak elemen berdasarkan nilai atributnya, tanpa perlu menambah class.

[type="text"]

Sama persis — atribut bernilai persis teks ini.

[type="text"] { border: 1px solid #00D9C0; }

[href^="https"]

Dimulai dengan — ^= untuk prefiks.

a[href^="https"] { color: #22c55e; }

[class*="btn"]

Mengandung — *= cocok di mana pun dalam nilai.

[class*="btn"] { font-weight: 700; }

[href$=".pdf"]

Diakhiri dengan — $= untuk sufiks.

a[href$=".pdf"] { color: var(--pink); }
Pseudo-element

::before & ::after

Menambahkan "elemen bayangan" di depan/belakang sebuah elemen — tanpa menulis HTML. Wajib punya content:"".

::before Muncul di bagian awal elemen.
::after Muncul di bagian akhir elemen.
content Isi ornamen: teks, ikon, emoji, atau kosong.
::selection Bonus: gaya saat teks disorot (di-select).

style.css

.judul::before { content: "🚀 "; } .tombol::after { content: " →"; font-weight: 700; }

Pseudo-class Lanjutan

Posisi & kondisi elemen

Pseudo-class bukan cuma :hover — bisa menembak berdasarkan urutan & status.

li:nth-child(2)

Elemen anak urutan ke-2 (juga odd/even).

li:nth-child(2) { color: #FF4D8D; }

p:not(.x)

Semua <p> kecuali yang punya class .x.

p:not(.x) { opacity: 0.9; }

input:focus

Saat kotak input sedang diklik/diketik.

input:focus { border-color: var(--css); }

form:focus-within

Seluruh form ikut berubah jika salah satu isinya fokus.

form:focus-within { box-shadow: ...; }

💡 Tabel zebra tanpa class manual: tr:nth-child(even) { background: rgba(255,255,255,0.04); }

Peralihan

Perubahan halus

Tanpa transition, perubahan gaya terjadi mendadak. Dengan transition, perubahan itu dianimasikan mulus dalam waktu tertentu.

transition-property Property apa yang dianimasikan.
transition-duration Berapa lama (mis. 0.3s).
transition-timing-function Kurva: ease, linear, ease-in-out.
transition: all .3s Shorthand paling umum.

style.css

.tombol { background: #1A2229; transition: all .4s ease; } .tombol:hover { background: #FF4D8D; transform: translateY(-4px); }

Animasi Penuh

@keyframes — animasi berjalan sendiri

Transition butuh pemicu (hover). Keyframes berjalan otomatis, bisa diulang & dikendalikan penuh.

@keyframes nama Deklarasi kumpulan frame.
from → to Frame awal & akhir (atau 0% → 100%).
animation-iteration-count infinite = terus-menerus.
animation-direction alternate = bolak-balik.

style.css

@keyframes mengambang { 0%, 100% { transform: translateY(0); } 50% { transform: translateY(-12px); } } .lambang { animation: mengambang 2.5s ease-in-out infinite; }

float (infinite)

spin (infinite)

Transform

Mengubah bentuk & posisi

Transform menggeser, memutar, membesar, memiringkan elemen — termasuk membuat efek kartu flip 3D.

translate(x, y) Menggeser elemen.
rotate(deg) Memutar elemen.
scale(n) Membesar / mengecil.
skew(deg) Memiringkan elemen.

style.css — rotasi 3D

.flip { perspective: 900px; } .kartu:hover { transform: rotateY(180deg); }

Gradasi Warna

Gradient menghidupkan latar

Gradient adalah transisi bertahap antara dua warna atau lebih — bisa dibuat teks berwarna-warni juga.

linear-gradient(135deg, a, b) Garis lurus diagonal.
radial-gradient(c, d) Melingkar dari tengah.
conic-gradient Melingkari titik (roda warna).
background-clip:text Trik teks berwarna gradien.

style.css

.kartu { background: linear-gradient(135deg, #FF4D8D, #8B5CF6); } .judul { background: linear-gradient(135deg, #FFD23F, #FF4D8D); -webkit-background-clip: text; color: transparent; }

Bayangan

Shadow untuk kedalaman

Bayangan membuat elemen terasa "terangkat" dari layar, atau menyala (glow). Pakai beberapa layer untuk hasil lebih halus.

box-shadow Bayangan di luar kotak. Format: x y blur spread warna.
text-shadow Bayangan pada teks.
0 20px 40px -12px #... Resep umum shadow lembut & realistik.

style.css

.kartu { box-shadow: 0 12px 30px -10px rgba(0,0,0,0.5); } .logo { text-shadow: 0 0 12px #FF4D8D; }

Filter Efek

Filter & efek kaca

Filter mengubah tampilan elemen seperti di aplikasi edit foto. backdrop-filter menerapkan efek ke latar di belakang elemen — rahasia tampilan kaca (glassmorphism).

blur(px) Mengaburkan.
brightness(n) Mengatur kecerahan.
hue-rotate(deg) Memutar roda warna.
backdrop-filter: blur() Kaca buram di belakang elemen.

style.css

.foto { filter: brightness(1.2) saturate(1.3); } .navbar { backdrop-filter: blur(12px); background: rgba(255,255,255,0.08); }

Fungsi CSS

Ukuran yang berhitung

CSS bisa menghitung sendiri. Inilah senjata utama layout yang fleksibel.

calc()

Menghitung kombinasi satuan — misal sisakan tempat untuk navbar.

.konten { width: calc(100% - 40px); }

clamp()

Ukuran yang otomatis menyusut & tumbuh antara minimum & maksimum.

h1 { font-size: clamp(1.5rem, 4vw, 3rem); }

min()

Mengambil nilai terkecil — tidak akan melebihi batas.

.gambar { width: min(90%, 600px); }

max()

Mengambil nilai terbesar — selalu sekurang-kurangnya itu.

.tombol { width: max(160px, 30%); }
Posisi Lanjut

sticky & z-index

position:sticky membuat elemen "menempel" saat discroll. z-index menentukan siapa di atas.

position: sticky Menggabungkan relatif + fixed.
z-index: 1 Semakin besar angka, semakin di depan.
z-index: -1 Bisa dikirim ke belakang elemen lain.
💡 z-index hanya bekerja pada elemen dengan position yang bukan static.

Flexbox Pro

Kendalikan ukuran item

Properti di item (anak) mengatur seberapa besar dia tumbuh / menyusut.

flex-grow: 1

Item mengisi sisa ruang. Angka menentukan proporsi.

flex-shrink: 0

Mencegah item menyusut saat ruang sempit.

flex-wrap: wrap

Membiarkan item turun baris (sudah di CSS Dasar, sering dipakai!).

order: n

Mengubah urutan tampil tanpa mengubah HTML.

1→2 2→1
Grid Pro

Layout dengan area bernama

Grid bisa "menggambar" peta layout dengan kata-kata — sangat mudah dibaca manusia.

style.css — grid-template-areas

.layout { display: grid; grid-template-areas: "header header" "sidebar main" "footer footer"; grid-template-columns: 120px 1fr; } .header { grid-area: header; }

Responsif Pro

Mobile-first & breakpoint

Tulis dulu gaya untuk HP, lalu perlahan perbaiki untuk layar lebih besar.

style.css — pola mobile-first

.galeri { display: grid; gap: 12px; } h1 { font-size: clamp(1.8rem, 5vw, 3.5rem); } @media (min-width: 640px) { .galeri { grid-template-columns: 1fr 1fr; } } @media (min-width: 1024px) { .galeri { grid-template-columns: repeat(4, 1fr); } }
breakpoint umum 640px (HP) · 768px (tablet) · 1024px (laptop) · 1280px (desktop)
1 kolom → 2 → 4 kolom galeri bertambah kolom seiring layar membesar
clamp() untuk teks judul mengecil di HP, membesar di desktop — otomatis
Best Practices

Menulis CSS rapi & cepat

Jauhi !important

`!important` merusak kaskade. Gunakan spesifisitas yang benar, bukan memaksakan.

Nama class jelas

Pakai pola sederhana ala BEM: kartu, kartu--judul, kartu__harga.

Pakai variabel

Warna & jarak berulang → simpan di --var. Konsisten & mudah diubah.

Gunakan DevTools

Klik kanan → Inspect. Uji properti langsung tanpa perlu menulis ulang file.
