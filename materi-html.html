HTML Dasar

HTML adalah kerangka utama dari setiap website. Di sini kamu akan belajar cara menyusun struktur halaman web dari nol menggunakan tag-tag dasar.

Definisi

Bukan Bahasa Pemrograman,
tapi Bahasa Markah.

Menggunakan Tag

HTML membungkus teks dengan "tag" seperti <p> untuk paragraf atau <h1> untuk judul.

Fokus Struktur

Tugasnya hanya menyusun "kerangka" website. Menentukan mana yang judul, gambar, atau teks biasa.

Tanpa Logika

HTML tidak bisa berhitung, tidak bisa membuat keputusan (if/else). Dia hanya diam menampilkan struktur.

Anatomi Elemen

Seperti apa bentuk tag HTML?

Sebagian besar tag HTML punya struktur pembuka dan penutup. Di antara keduanya adalah isi (konten) dari tag tersebut.

<p> Tag Pembuka (Opening)
</p> Tag Penutup (Closing) — ditandai dengan garis miring /
Halo Dunia Konten (Content) — teks atau elemen lain di dalamnya
<p> Halo Dunia </p>
Kerangka Wajib

Setiap file HTML di dunia pasti dimulai dengan kerangka dasar ini. Tanpa ini, browser bisa bingung cara membaca halamanmu.

<head>

Berisi informasi yang TIDAK terlihat di layar (seperti judul tab browser).

<body>

Berisi SEMUA konten yang terlihat oleh pengguna di layar (teks, gambar, tombol).

index.html

<!-- Memberitahu ini file HTML5 --> <!DOCTYPE html> <html> <head> <title>Judul Websiteku</title> </head> <body> <!-- Konten web taruh di sini --> <h1>Halo Dunia!</h1> </body> </html>

Menyusun Teks

1. Heading (Judul)

Ada 6 level, dari <h1> (terbesar/paling penting) sampai <h6> (terkecil).

<h1>Judul Utama</h1> <h2>Sub Judul</h2> <h3>Sub Sub Judul</h3>

Tag Dasar 2

Menghubungkan & Menampilkan

3. Link (Tautan)

Menghubungkan ke halaman lain. Atribut href menentukan tujuan.

<a href="https://google.com"> Klik untuk ke Google </a>
Klik untuk ke Google

4. Image (Gambar)

Menampilkan gambar. Self-closing (tidak butuh penutup). src = sumber gambar, alt = teks cadangan.

<img src="logo.png" alt="Logo Sekolah">

Logo Sekolah

Tag Dasar 3

Membuat Daftar (List)

HTML punya dua jenis daftar. Di dalamnya wajib diisi dengan tag <li> (List Item).

<ul> Unordered List (Daftar berpoin)
<ol> Ordered List (Daftar bernomor)
<ul> <li>Apel</li> <li>Pisang</li> </ul>
  • Apel
  • Pisang
<ol> <li>Bangun pagi</li> <li>Mandi</li> </ol>
  1. Bangun pagi
  2. Mandi
Struktur Konten

Mengelompokkan dengan <div>

<div> adalah kotak kosong serbaguna. Digunakan untuk mengelompokkan beberapa tag menjadi satu kesatuan (biasanya untuk di styling CSS nanti).

Saat ini, ada juga tag semantik yang fungsinya sama seperti <div> tapi namanya menjelaskan isinya: <header>, <nav>, <section>, <footer>.

contoh.html

<div class="kartu-profil"> <img src="foto.jpg"> <h2>Budi</h2> <p>Pelajar RPL</p> </div>

Misimu: Halaman "Tentang Saya"

Buatlah halaman web pribadi sederhana menggunakan semua tag HTML dasar yang sudah dipelajari.

Syarat Wajib:

Judul Tab Browser

Gunakan <title> di dalam head.

Heading & Paragraf

Nama kamu sebagai <h1>, deskripsi diri di <p>.

Foto Profil

Gunakan <img> dengan atribut alt yang jelas.

Hobi / Cita-cita

Masukkan dalam bentuk daftar <ul> atau <ol>.

Tautan Media Sosial

Gunakan <a> untuk link Instagram/Tiktok kamu.

Pengelompokan

Bungkus profil dan hobi dengan <div> atau tag semantik.

Tugas dikumpulkan dalam format:

1 file bernama tugas_html_nama.html. Pastikan filenya bisa dibuka di browser (double click file) dan menampilkan layout yang rapi.
